# АИС «Магазин бытовых товаров»

Автоматизированная информационная система для управления розничным магазином бытовой техники. Проект разработан в рамках курсовой работы по дисциплине «Базы данных» (МГТУ им. Н.Э. Баумана, кафедра ИУ5).

Система представляет собой классическое клиент-серверное приложение (Desktop Client + SQL Database) с жестким разделением бизнес-логики на уровне СУБД (триггеры, представления) и графическим интерфейсом на C++/Qt.

## 🚀 Основной функционал

Проект реализует ролевую модель доступа со сквозным разделением интерфейса:

### 👑 Панель Администратора

* **Справочники:** Управление номенклатурой (категории, товары), персоналом и базой поставщиков.
* **Складская логистика:** Регистрация приходных накладных, автоматический пересчет складских остатков.
* **Аналитика и отчеты:** Выгрузка актуальных складских остатков, расчет КПЭ сотрудников, построение матрицы продаж и экспорт графических столбчатых диаграмм выручки в PDF.
* **Безопасность:** Регистрация новых пользователей, смена ролей и криптографическое хэширование паролей (SHA-256).

### 🛒 Панель Менеджера

* **CRM:** Ведение базы клиентов магазина.
* **Каталог:** Безопасный просмотр ассортимента и доступных складских остатков.
* **Продажи:** Формирование корзины, оформление заказов с автоматическим контролем остатков и генерацией фискального товарного чека (PDF).
* **Управление заказами:** Просмотр истории и изменение бизнес-статусов заказов (Принят, Оформляется, Оплачен, Доставлен, Отменен).

## 🛠 Технологический стек

* **Язык программирования:** C++17
* **Графический фреймворк:** Qt 5.12+ (Qt Widgets, Qt Charts, Qt Sql)
* **Система сборки:** CMake 3.14+
* **СУБД:** PostgreSQL 17+
* **Инфраструктура:** Docker, Docker Compose

## ⚙️ Установка и запуск

### 1. Подготовка базы данных (Серверная часть)

Для быстрого развертывания СУБД и инструмента администрирования используется Docker.

```bash
# Запуск контейнеров с PostgreSQL и pgAdmin
docker-compose up -d

```

*Примечание: Структура базы данных и тестовые данные загружаются из папки `db/`. Для ручной накатки используйте скрипты в порядке их нумерации (01 -> 05).*

### 2. Настройка окружения клиентской части

В корне папки сборки (`app/build/`) необходимо создать файл `.env` для подключения к БД:

```env
DB_HOST=127.0.0.1
DB_PORT=5432
DB_NAME=store_db
DB_USER=postgres
DB_PASSWORD=your_secure_password
```

Образец для его находится в файле `.env.dev`.

### 3. Сборка клиентского приложения

Для сборки приложения потребуется установленный CMake и компилятор C++.

```bash
cd app
mkdir build && cd build
cmake ..
make
```

### 4. Запуск

```bash
./ShopApp
```
